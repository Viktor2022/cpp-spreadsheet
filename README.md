## Электронная таблица (аналог Microsoft Excel)

### Описание проекта

Разработка backend-системы электронной таблицы с поддержкой формул и зависимостей между ячейками, аналогичной функциональности Microsoft Excel.

### Технологии и инструменты

- **C++** с современными стандартами
- **CMake** для сборки проекта
- **ANTLR** для парсинга математических формул
- **Система тестирования** для покрытия функционала

### Запуск проекта

**Требования к окружению:**

- Установленный компилятор C++
- CMake версии 3.x и выше
- ANTLR-библиотека

**Инструкция по сборке:**

```bash
mkdir build
cd build
cmake ..
make
```

### Архитектура системы

**Основные компоненты:**

- **Ячеечная система** для хранения данных
- **Парсер формул** на базе ANTLR
- **Система вычислений** с обработкой зависимостей
- **Механизм кеширования** значений ячеек
- **Механизм валидации** данных

**Базовые возможности:**
